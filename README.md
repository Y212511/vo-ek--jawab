# वो एक जवाब… — GitHub Pages Website

This is a mobile-friendly public website for the perfect comic edition supplied by the author.

## Included files
- `index.html` — mobile-friendly homepage, online PDF reader and chapter navigation
- `vo-ek-jawab-comic.pdf` — the uploaded 21-page comic edition
- `cover-preview.jpg` — preview generated from page 1 of that exact PDF

## Publish from a new GitHub repository
1. Create a **Public** repository on GitHub. Suggested name: `wo-ek-jawab`.
2. Extract this ZIP on your phone or computer.
3. Upload the three files above directly into the repository root (not inside another folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then press **Save**.
7. Wait for GitHub Pages to finish publishing.

The site URL will look like `https://YOUR-USERNAME.github.io/wo-ek-jawab/`.

## Important
- This is a public website. Anyone with the link can view and download the comic PDF.
- The PDF viewer is embedded; some mobile browsers may open PDFs in a separate tab. The download and new-tab links are provided as alternatives.
- Chapter links point to the physical page numbers in the included PDF edition.
